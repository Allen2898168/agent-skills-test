# Temp Workflow Staging Area

本目录用于暂存已跑通但用户明确要求暂时不写入 skill、也不写入交接文档的后台流程。

## 使用规则

- 只有当用户明确要求某个流程“暂时不写入 skill / 不写交接文档”且流程已经实际跑通时，才写入本目录。
- 内容按业务域分级，不把所有流程堆到单个文件。
- 不保存真实密码、验证码、token、cookie、API key 或个人敏感信息。
- 暂存内容应包含：
  - 操作名称。
  - 环境和入口 URL。
  - 前置条件。
  - 已验证配置项。
  - 操作步骤。
  - 成功断言。
  - 失败重试记录和业务限制。
  - 最近验证日期。
  - 是否已经纳入 skill。
- 每次新会话开始时，如果本目录存在内容，只需读取本文件或业务索引摘要。
- 只有当前任务与暂存流程相关，或用户明确要求继续、迁移暂存流程时，才汇总暂存区，并询问用户：
  - 是否从暂存区流程继续。
  - 是否将暂存区内容正式落到 `skills/weex-admin-ops/`。
- 当用户要求将某条暂存流程落到 skill 后，完成 skill 更新并验证无遗漏后，应删除本目录中对应的暂存文件或将其标记为已迁移。
