# 活动通用模块管理失败复盘

## 2026-05-06 活动流程引导配置 NONE 创建失败
- 业务线：活动通用模块管理 / 活动流程引导配置。
- 场景：按新增弹窗活动类型下拉选项创建引导模板，活动类型选择 `暂无特殊配置`，后端值为 `NONE`。
- 失败表现：不可见模式和可见浏览器模式下，`POST /prod-api/activity/guideTemplate` 均返回 HTTP 200，但业务 `code=500`，提示 `系统繁忙，请稍后再试！`；按模板名称未回查到记录。
- 失败原因：页面下拉展示了 `NONE` 选项，但当前后端创建接口不接受或未正确处理该活动类型，具体后端规则待确认。
- 解决方式：本轮将 `NONE` 视为阻塞分支，其他 12 个活动类型按 `每次访问` 创建成功；交易大赛 3 个频率和 2 步骤分支也创建成功。
- 验证结果：不可见模式创建成功 ID `39`-`53` 中除 `NONE` 外 15 条；可见模式创建成功 ID `54`-`68` 中除 `NONE` 外 15 条；两种模式的 `NONE` 均无新增记录。
- 关联流程或脚本：本轮活动流程引导配置 inline 探测/创建脚本。
- 后续处理：沉淀正式流程时应把 `暂无特殊配置 / NONE` 标为已知后端阻塞分支；如需覆盖该选项，先让后端确认合法参数或修复接口。

## 2026-05-06 活动流程引导配置操作列固定列定位失败
- 业务线：活动通用模块管理 / 活动流程引导配置。
- 场景：验证操作列 `查看 / 修改 / 复制 / 删除`，按模板名称搜索到临时记录后点击行内按钮。
- 失败表现：初次可见浏览器尝试命中了 Element UI 固定列生成的隐藏按钮副本；后续通用 `clickRowActionByText` 只在包含业务名称的主表行内查找按钮，在活动流程引导配置页面找不到 `查看` 按钮。一次失败创建了临时 ID `79`。
- 失败原因：Element UI 表格主内容列和右侧固定操作列分属不同 DOM 行；固定操作列行不包含模板名称，且页面可能同时存在隐藏副本。
- 解决方式：更新公共表格 helper，先在可见主表行中按业务文本定位行序号，再到可见右侧固定操作列同序号行内点击可见按钮。临时 ID `79` 已通过页面 `删除` 按钮和二次确认弹窗清理。
- 验证结果：修正后无浏览器模式临时 ID `80`、复制 ID `81` 完成查看、修改、复制、删除并清理；可见浏览器模式临时 ID `82`、复制 ID `83` 完成同样验证并清理。
- 关联流程或脚本：`scripts/guide-template-row-actions.mjs`；公共 helper `scripts/lib/element-ui-table.mjs`。
- 后续处理：其他 Element UI 固定操作列表格应复用公共 `clickRowActionByText`，避免直接使用 raw `button:has-text(...)`。

## 2026-05-06 活动流程引导配置复制按钮无确认弹窗
- 业务线：活动通用模块管理 / 活动流程引导配置。
- 场景：验证操作列 `复制`。
- 失败表现：脚本点击 `复制` 后等待二次确认弹窗超时。
- 失败原因：该页面的 `复制` 按钮直接触发 `POST /prod-api/activity/guideTemplate/copy`，未观察到确认弹窗；只有 `删除` 存在二次确认弹窗。
- 解决方式：复制动作改为等待 `POST /copy` 并按 `复制从 <原模板名称>` 精确搜索验证新记录；删除动作继续等待 `确认删除该活动吗` 的二次确认弹窗。
- 验证结果：无浏览器模式复制 ID `81`、可见浏览器模式复制 ID `83` 均按命名规则创建成功，随后通过 UI 删除并回查不存在。
- 关联流程或脚本：`scripts/guide-template-row-actions.mjs`；`references/operations/activity-guide-template.md`。
- 后续处理：不要把复制按钮写成有确认弹窗的流程；如页面行为改动，优先以接口响应和弹窗实际状态重新验证。

## 2026-05-06 活动流程引导配置操作列缓存误命中创建动作
- 业务线：活动通用模块管理 / 活动流程引导配置。
- 场景：对自然语言 `活动流程引导配置 操作列 查看 修改 复制 删除 浏览器模式` 做动作缓存 dry-run。
- 失败表现：缓存匹配到了 `create_guide_templates`，不是操作列验证动作。
- 失败原因：原缓存只有创建引导模板动作，且 `活动流程引导配置` 的创建动作评分过高；操作列链路尚未登记独立动作。
- 解决方式：新增 `verify_guide_template_row_actions` 缓存动作和脚本，匹配器对 `活动流程引导配置 + 操作列` 提升操作列动作评分。
- 验证结果：显式 action dry-run 和自然语言 dry-run 均命中 `scripts/guide-template-row-actions.mjs`。
- 关联流程或脚本：`scripts/action-cache.json`、`scripts/cache/matcher.mjs`、`scripts/cache/command.mjs`。
- 后续处理：新增同一页面不同意图动作时，要用 `supportedActions`、业务关键词和动作专属评分避免误命中。
