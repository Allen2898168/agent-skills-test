# 代理小活动（AGENT_TRACE_PRO）模块：key -> 前端中文名映射

说明：
- 代理小活动与小活动型活动共用后管页面 `/activities/copyTrading`，通过“类别配置(channelCategory)=AGENT”区分。
- 该表用于把“模块 key”映射为前端可见的中文模块名，便于对话配置与脚本 spec 填参。

| 模块 key | 前端中文名 |
| --- | --- |
| `base` | 活动基本信息 |
| `material` | 合伙人后台信息 |
| `registration` | 报名信息 |
| `subActivities` | 小活动信息 |
| `tradingPairInfo` | 交易币对信息 |
| `resourceCard` | 资源位信息卡片 |
| `rules` | 活动规则信息 |
| `faq` | 常见问题 |
| `calendar` | 活动日历 |
| `entry` | 路径转化入口 |
| `activityData` | 活动数据信息 |
| `userData` | 单用户数据信息 |
