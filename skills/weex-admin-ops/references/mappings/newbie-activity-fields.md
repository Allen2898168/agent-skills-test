# 新手活动（BEGINNER_TASK）字段：key -> 前端中文名映射

用途：用于对话配置与 `newbie-activity-module-config-fast-api.mjs` / `newbie-config-wizard-api.mjs` 的字段提示。

| 字段 key | 前端中文名 |
| --- | --- |
| `title` | 活动标题 |
| `showUrl` | 活动别名（showUrl） |
| `startTime` | 活动开始时间 |
| `endTime` | 活动结束时间 |
| `applyConfigId` | 用户报名模版 |
| `tasks.mode` | 任务模式（custom/taskPackage） |
| `tasks.taskIds` | 自定义任务ID列表 |
| `tasks.routineTaskIds` | 日常任务ID列表 |
| `tasks.taskPackageId` | 任务包ID |
| `tasks.routineTaskPackageId` | 日常任务包ID |
| `tasks.routineTitle` | 日常任务标题 |
| `tasks.routineSubTitle` | 日常任务副标题 |
| `resourceCard.resourceCardIds` | 资源位卡片ID列表 |
| `i18n.activityConfigI18n` | 多语言配置（activityConfigI18n） |
| `faq.questions` | 常见问题（questions） |
