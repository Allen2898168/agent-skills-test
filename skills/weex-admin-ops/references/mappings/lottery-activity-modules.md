# 转盘抽奖（LOTTERY）模块：key -> 前端中文名映射

用途：把模块 key 映射为前端可见中文模块名，用于对话配置与模块级 spec 填参。

| 模块 key | 前端中文名 |
| --- | --- |
| `base` | 基础信息（含报名/展示/分享基础字段） |
| `style` | 抽奖样式 |
| `tasks` | 任务配置 |
| `prize` | 奖品池配置（8个位置） |
| `prizeWeight` | 累计次数再权重配置 |
| `colorTag` | 色签权重配置 |
| `dailyLimit` | 每日限制配置 |
| `probability` | 抽奖概率/权重配置 |
| `i18n` | 多语言 |
| `faq` | 常见问题 |
| `calendar` | 活动日历 |
| `preApply` | 预报名 |
