# Failure Review Docs

## 写入规则

- 通用问题写入 `common.md`。
- 页面或业务域问题写入对应 `<domain>.md`；文件不存在时再创建。
- 不保存真实密码、token、cookie、API key、完整账号凭证或个人隐私数据。
- 如果同类问题第二次出现且本次解决方式有效，优先把解决方式固化到流程、helper、selector 或缓存脚本，再把复盘条目标记为已吸收。

## 复盘模板

```markdown
## <场景标题>

- 日期：
- 页面/流程：
- 环境/viewport：
- 失败表现：
- 失败原因：
- 解决方式：
- 验证结果：
- 关联流程或脚本：
- 后续处理状态：
```
