# 转盘抽奖自动化回归落地方案

## 文档说明

- 适用范围：WEEX 转盘抽奖活动的后管自动化回归、前端自动化回归、专项自动化回归。
- 当前目标：把已沉淀的后管 56 条、前端 84 条回归用例，拆成可持续执行的自动化主回归与专项回归。
- 当前原则：先落稳定主链路，再补专项；不把高波动、低复现、强并发场景直接塞进日常全量回归。

## 一、自动化目标

本方案希望解决 4 件事：

1. 让转盘抽奖的后管和前端回归可以按固定链路重复执行。
2. 让活动、账号、任务、库存等测试数据不互相污染。
3. 让自动化执行不仅能“跑动作”，还能判断结果是否正常。
4. 让专项场景和日常主回归分层，避免一次回归依赖过多复杂前置条件。

## 二、自动化范围分层

### A. 稳定主回归

适合日常执行，优先自动化：

- 后管：
  - 活动列表
  - 报名模版
  - 任务管理
  - 奖品管理
  - 活动配置 / 活动信息
  - 上下线 / 状态流转
- 前端：
  - 页面基础 UI
  - 抽奖样式 UI
  - 页面状态 UI
  - 按钮与交互态
  - 单抽主流程
  - 我的奖品 / 奖励记录
  - 前后端联动展示

### B. 专项回归

适合按需执行，单独活动隔离：

- 五连抽专项
- 二次权重专项
- 小库存 / 无库存专项

### C. 暂不纳入当前自动化主回归

- 多账户并发抢奖

当前用户已明确：并发问题先不用管，当前按单账户自动化回归执行。

## 三、测试数据与活动隔离策略

### 1. 活动隔离

每次回归使用新活动，不复用旧活动。

活动至少拆成 3 类：

- `普通回归活动`
- `二次权重专项活动`
- `小库存专项活动`

活动获取方式支持两种：

- 新建活动
- 从活动列表复制活动后再修改

当前已确认：

- 活动复制 bug 已修复，可以作为自动化活动准备路径的一部分。
- 在 `活动列表 / 转盘抽奖` 页面，操作栏包含 `查看 / 修改 / 下线 / 复制` 等按钮。
- 点击 `复制` 后，会生成一个新的草稿状态活动。
- 活动前端访问 URL 规则为 `https://stg-www.weex.tech/zh-CN/events/draw/<活动别名>`。

### 2. 专项活动用途

`普通回归活动`：
- 用于后管主链路
- 用于前端页面展示
- 用于前端单抽主流程

`二次权重专项活动`：
- 仅用于验证累计次数再权重场景
- 不与普通活动共用

`小库存专项活动`：
- 用于库存不足 / 奖品被抢光场景
- 可以专门建成无库存或低库存活动

## 四、前置流程标准化

前端自动化回归不应直接从“打开活动页点击抽奖”开始，而应先完成前置链路。

标准前置流程：

1. 创建或复制本轮目标活动。
2. 根据回归类型，配置活动：
   - 普通活动
   - 二次权重活动
   - 小库存活动
3. 绑定报名模版。
4. 绑定抽奖任务。
5. 配置奖池。
6. 上线活动。
7. 使用固定测试账号登录前端。
8. 报名参加活动。
9. 完成前置任务，获取抽奖次数。
10. 打开活动前端页，执行对应前端用例。

## 五、活动页入口与报名规则

当前已真实验证的稳定规则：

1. 转盘抽奖活动前端页必须通过活动别名访问：
   - `https://stg-www.weex.tech/zh-CN/events/draw/<活动别名>`
2. 活动必须先在后管完成 `上线`，再进入前端验证。
3. 活动未开始时，前端主按钮应展示 `即将开始`。
4. 活动进行中且当前用户未报名时，前端主按钮应展示 `立即报名`。
5. 点击 `立即报名` 后，`apply` 接口成功返回时，主按钮应从 `立即报名` 切换为 `抽奖`。
6. 已报名账号再次进入同一活动页时，不应再次展示 `立即报名`，应直接展示 `抽奖`。

报名能力的最小自动化闭环应包含：

1. 登录固定测试账号。
2. 打开活动别名 URL。
3. 判断当前按钮状态：
   - `即将开始`
   - `立即报名`
   - `抽奖`
4. 若为 `立即报名`，执行点击报名。
5. 断言报名成功：
   - `apply` 接口返回成功
   - 页面主按钮切换为 `抽奖`
6. 再次打开同一活动页，断言报名状态保持。

## 六、抽奖次数前置发放规则

当前已确认：前端回归前，需要先完成这些任务以获取抽奖次数：

- `合约交易量任务`
- `充值任务`

因此自动化回归要补一个固定前置能力：

- 先完成任务
- 再验证抽奖次数到账
- 次数到账后再进入前端抽奖

抽奖次数前置校验建议：

1. 活动页剩余抽奖次数显示正确。
2. 可用次数满足本轮测试要求：
   - 单抽：至少 `1`
   - 五连抽：至少 `5`
