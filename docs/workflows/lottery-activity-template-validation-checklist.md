## 一、普通回归活动模板（已验证）

### 目标

生成一个可稳定用于日常后管和前端主回归的转盘抽奖活动。

### 模板字段

| 字段 | 目标值 |
| --- | --- |
| 配置类型 | `正式活动` |
| 负责人 | `auto-test` |
| 类别配置 | `通用` |
| 流程引导配置 | `37 - 转盘活动 - 自动化测试引导配置` |
| 是否为平台活动 | `是` |
| 活动标题 | 运行时使用 15 字内短标题，例如 `回归转盘03` |
| 活动副标题 | 运行时使用 15 字内短副标题，例如 `普通回归模板` |
| 活动时间 | 运行时填写开始/结束时间 |
| 用户报名模版 | `【2781】 全用户转盘报名模板_全平台用户_auto_manual_20260512064613` |
| 头图/分享图 | 使用 skills 默认图片，上传前勾选压缩 |
| 分享活动文案 | `分享活动文案分享` |
| 代理分享文案 | `分享活动文案分享` |
| 活动规则 | 描述本次测试场景的测试用例标题和预期结果 |
| 活动别名配置 | `autotest-<yyyymmddhhmmss>-normal` |
| 是否支持预报名 | `不支持` |
| 是否显示活动日历入口 | `是` |
| 抽奖样式 | `圆形转盘` |
| 抽奖奖品配置 | 尽量读取已有多种奖品；库存 `100`；8 个奖品权重合计 `100`；图片使用默认图；奖品标记覆盖 `大奖/中奖/小奖` |
| 颜色签配置 | 红签 8 个奖品权重合计 `100%`；白签 8 个奖品权重合计 `100%` |
| 配置分享信息 | 8 个奖品均上传默认图；填写中文分享文案和奖品名称 |
| 奖品每日限制配置 | `不配置` |
| 累计次数再权重配置 | `不配置` |
| 活动任务信息 | 优先读取已有多个不同任务；若无，固定使用 `4998`、`4997`、`4996`、`5102` |
| 多语言 | 勾选英语，填写英文标题、副标题、头图、分享图、分享文案、代理分享文案、活动规则 |
| 常见问题 | 勾选英语，填写标题和内容 |
| 活动日历 | `同步` |
| 提交动作 | 点击 `新增` |

### 验证通过标准

1. 成功打开新增页并完成所有模板字段填写。
2. 点击 `新增` 后接口成功。
3. 列表按活动别名可搜索到该活动。
4. 活动状态为 `草稿`。
5. 编辑页回显与模板配置一致。

## 四、本轮验证结论

本轮真实创建已确认这些能力具备：

1. 自定义负责人、平台活动、引导配置、固定报名模版是否可稳定选择。
2. 支持关闭预报名且不填写预报名时间。
3. 可不配置 `奖品每日限制配置`。
4. 可按需要开启或不配置 `累计次数再权重配置`。
5. 可绑定 4 个固定任务：`4998`、`4997`、`4996`、`5102`。
6. 多语言、FAQ、活动日历均可在同一条链路中成功保存。

## 五、沉淀结论

1. 这 3 个模板已可以作为 `转盘抽奖活动自动化回归` 的权威模板定义。
2. 后续普通主回归优先使用 `普通回归活动模板`。
3. 二次权重和库存不足场景应分别使用独立专项模板，不与普通回归活动共用。
