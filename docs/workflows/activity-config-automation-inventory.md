## 8. 下一步建议

- 第一步：先把每个活动类型的“最小配置创建 -> 回查 -> 删除”无头链路补齐。
- 第二步：再补各活动类型 `P1` 模块级保存/回查。
- 第三步：最后再补对应前端 landing page / 展示联动。

这样做的好处是：

- 先打通后管写入能力，自动化可快速铺开。
- 前端联动只在后管最小链路稳定后再接，不会把两个问题混在一起。
- 后续用户说“创建一个某某活动”时，可以先命中该活动的 `wizard + minimal preset`，再按模块递进扩展。
