## 文档说明

- 需求来源：[/Users/gabriel/Downloads/WWLD-13435【大富翁】世界杯.md](/Users/gabriel/Downloads/WWLD-13435【大富翁】世界杯.md)
- 适用范围：WEEX 活动后台 `活动列表 / 大富翁世界杯（MONOPOLY_WORLD_CUP）`
- 当前口径：以后管配置、发布、配置回查、上下线校验为主，不覆盖前端交互细节与 FIN 发奖审核

## 后管范围判断

结合需求文档、项目 skill 映射和现有后管实现，当前后管重点覆盖以下 10 个配置模块与 1 组状态流转能力：

| 模块 | 说明 |
| --- | --- |
| 基本信息 | 活动时间、别名、负责人、多语言基础信息、分享信息 |
| 用户报名 | 报名模板绑定，且仅支持 `用户手动点击报名` |
| 未登录说明内容 | 未登录状态图文配置 |
| 配置管理 | 默认/官网/渠道配置切换与可见性隔离 |
| 棋盘配置 | 16 格棋盘、格子奖励、显示数量、真实库存、兜底格 |
| 奖励列表 | 积分池奖品、总数、排序 |
| 任务配置 | 新手、每日、累计、积分里程碑、竞猜、膨胀券、分享任务等 |
| 风控阈值 | 分层阈值与发放比例 |
| 常见问题 | FAQ 多语言配置 |
| 活动日历 | 日历同步与配置 |
| 状态流转 | 草稿检查、上线、下线、删除、审计追踪 |

## 执行前置条件

- 环境：staging
- 已具备活动后台登录态
- 已准备 Google 验证码来源，用于上线、下线、删除等确认动作
- 已准备或可临时创建以下依赖数据：
  - 符合大富翁约束的报名模板
  - 虚拟奖品
  - 大富翁任务
- 需求中未明确的高风险项需单独确认：
  - 活动开始时间、结束时间
  - 官网/渠道分组规则
  - 风控阈值与发放比例
  - 奖励真实库存
  - 分享任务验真规则

## 非目标范围

- 不覆盖前端 Web/H5 页面动效与视觉验收
- 不覆盖钱包/账务/风控中心内部实现，只验证后管配置是否能正确提交和回查
- 不覆盖 FIN Admin 审核流
- 不覆盖埋点平台真实上报，只覆盖后管是否存在对应配置依赖和联动入口

## 共性检查项

- 不能只看 HTTP 200，必须同时做列表回查、详情回查或编辑回显校验
- 凡是页面出现长度计数或 `maxlength`，都应顺手校验边界
- 涉及官网/渠道双配置时，必须验证保存后互不覆盖
- 任务、奖品、报名模板均需验证真实 ID 已成功绑定，而不是只验证页面显示文本
- 风控阈值、奖励库存、活动时间属于高风险字段，测试数据必须单独标注
- 发布链路必须验证状态流转，不得只验证按钮点击成功
