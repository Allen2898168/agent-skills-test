# 会话交接归档索引

本目录保存历史交接记录。当前接力只读 `docs/session-handoff.md`；需要追溯历史时再读取对应业务域文件。

- `setup-and-skill-history.md`：项目初始搭建、skill 文件清单和资产规则。
- `process-rules-history.md`：需求确认、沉淀、动作缓存、组件复用、登录稳定性等规则演进。
- `prize-management-history.md`：奖品管理早期搜索、新增和截图证据。
- `prize-management-actions.md`：奖品管理行操作和复制缓存。
- `activity-task-core-a.md` / `activity-task-core-b.md`：活动任务搜索、奖励模式、任务条件和重试阻塞。
- `activity-task-participant-a.md` / `activity-task-participant-b.md`：转盘抽奖参与范围、缓存脚本和多语言修正。
- `activity-register-basic-a.md` / `activity-register-basic-b.md`：活动用户报名管理基础探测、创建和权限参数。
- `activity-register-platform-a.md` / `activity-register-platform-b.md`：报名模板平台范围流程。
- `activity-register-recent.md`：最近报名模板创建记录、注册时间范围、下一步和安全说明。
- `joker-activity.md`：小丑牌活动多语言回填链路。
- `frontend-ops-register.md`：前端页面操作 skill、STG 登录和邮箱注册链路探测。
