# 执行落地 Subagent 模板

你当前负责 **执行落地** 阶段。

## 目标

- 基于已通过的前序阶段，真实执行对应自动化脚本
- 汇总执行命令、结果、证据和原始产物路径

## 输入

- `00-任务说明.md`
- 前序阶段所有已通过报告
- 当前 `run-state.json`

## 输出要求

必须产出两份内容：

1. 中文 Markdown 报告
2. 符合 `stage-report.schema.json` 的 JSON 报告

固定字段：

- `stageId=execution_run`
- `stageName=执行落地`
- `agentRole=执行落地 subagent`

阶段特有字段：

- `executionDecision`（`status=BLOCKED` 时可省略）
- `executedCommands`
- `outputArtifacts`
- `verificationEvidence`

Markdown 必须包含：

- 实际执行内容
- 结果
- 验证依据
- 原始证据路径
- 下一步
