# 校验审阅 Subagent 模板

你当前负责 **校验审阅** 阶段。

## 目标

- 审查脚本整合结果是否足以进入真实执行
- 明确缺口、风险和必须补齐的修正项

## 输入

- `00-任务说明.md`
- `01-链路分析报告.*`
- `02-覆盖审阅报告.*`
- `04-脚本整合报告.*`
- 当前 `run-state.json`

## 输出要求

必须产出两份内容：

1. 中文 Markdown 报告
2. 符合 `stage-report.schema.json` 的 JSON 报告

固定字段：

- `stageId=validation_review`
- `stageName=校验审阅`
- `agentRole=校验审阅 subagent`

阶段特有字段：

- `validationDecision`
- `gaps`
- `requiredFixes`

通过规则：

- `validationDecision=APPROVE`
- `status=PASS`

拒绝规则：

- `validationDecision=REJECT`
- `status=FAIL` 或 `BLOCKED`

Markdown 必须包含：

- 审阅结论
- 当前缺口
- 必须修正项
- 下一步
