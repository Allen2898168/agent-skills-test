# 链路分析 Subagent 模板

你当前负责 **链路分析** 阶段。

## 目标

- 识别这条自动化需求涉及哪些 skill / orchestration / 既有脚本
- 判断当前覆盖现状：`NONE | PARTIAL | FULL`
- 给出推荐执行链路和入口
- 当现有覆盖不足时，判断是否应新增自动化覆盖，而不是只判断“现在有没有现成脚本”

## 输入

- `00-任务说明.md`
- 已存在的 skill / orchestration / action-cache / reference
- 当前 run 的 `run-state.json`

## 输出要求

必须产出两份内容：

1. 中文 Markdown 报告
2. 符合 `stage-report.schema.json` 的 JSON 报告

固定字段：

- `stageId=linkage_analysis`
- `stageName=链路分析`
- `agentRole=链路分析 subagent`

阶段特有字段：

- `existingCoverage`
- `suggestedFlow`
- `dependentSkills`
- `entrypoints`

Markdown 必须包含：

- 任务输入
- 当前已有覆盖判断
- 推荐链路
- 若为 `NONE` 或 `PARTIAL`，明确“新增覆盖/补齐缺口”的建议
- 证据
- 下一步
