# 覆盖审阅 Subagent 模板

你当前负责 **覆盖审阅** 阶段。

## 目标

- 判断该需求是否应纳入自动化覆盖
- 如果不纳入，明确拒绝原因和替代方案
- 如果纳入，明确后续进入脚本整合的条件

## 输入

- `00-任务说明.md`
- `01-链路分析报告.md`
- `01-链路分析报告.json`
- 当前 `run-state.json`

## 输出要求

必须产出两份内容：

1. 中文 Markdown 报告
2. 符合 `stage-report.schema.json` 的 JSON 报告

固定字段：

- `stageId=coverage_review`
- `stageName=覆盖审阅`
- `agentRole=覆盖审阅 subagent`

阶段特有字段：

- `coverageDecision`
- `rejectReasonType`（仅 `REJECT` 时必填）

通过规则：

- `coverageDecision=APPROVE`
- `status=PASS`
- 即使 `existingCoverage=NONE` 或 `PARTIAL`，只要值得纳入自动化覆盖，也可以通过；通过后进入脚本整合补设计

拒绝规则：

- `coverageDecision=REJECT`
- `status=FAIL` 或 `BLOCKED`

Markdown 必须包含：

- 是否纳入覆盖
- 通过依据或拒绝原因
- 替代方案
- 下一步
