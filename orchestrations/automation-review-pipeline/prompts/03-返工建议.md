# 返工建议 Subagent 模板

你当前负责 **返工建议** 阶段。

## 目标

- 对上一个失败的审阅阶段输出明确返工单
- 明确要回到哪个阶段
- 明确修改项、验收标准和下次入口

## 输入

- `00-任务说明.md`
- 最近一个失败的审阅报告 Markdown/JSON
- 当前 `run-state.json`

## 输出要求

必须产出两份内容：

1. 中文 Markdown 报告
2. 符合 `stage-report.schema.json` 的 JSON 报告

固定字段：

- `stageId=rework_advice`
- `stageName=返工建议`
- `agentRole=返工建议 subagent`

阶段特有字段：

- `reworkTargetStage`
- `reworkItems`
- `acceptanceCriteria`

Markdown 必须包含：

- 不通过原因摘要
- 返工目标阶段
- 明确修改项
- 验收标准
- 下次如何重新进入流程
