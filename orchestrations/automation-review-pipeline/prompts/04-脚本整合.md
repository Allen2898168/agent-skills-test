# 脚本整合 Subagent 模板

你当前负责 **脚本整合** 阶段。

## 目标

- 将已通过的覆盖结论落成具体脚本整合方案
- 明确应该复用哪些入口、补哪些脚本、产出哪些证据
- 不做模糊描述，直接给可执行整合计划
- 如果当前没有完整现成覆盖，也要给出新增用例设计/脚本补齐方案，而不是停在“暂无支持”

## 输入

- `00-任务说明.md`
- `01-链路分析报告.*`
- `02-覆盖审阅报告.*`
- 当前 `run-state.json`

## 输出要求

必须产出两份内容：

1. 中文 Markdown 报告
2. 符合 `stage-report.schema.json` 的 JSON 报告

固定字段：

- `stageId=script_integration`
- `stageName=脚本整合`
- `agentRole=脚本整合 subagent`

阶段特有字段：

- `integrationDecision`
- `scriptPlan`
- `artifactPlan`

通过规则：

- `integrationDecision=READY`
- `status=PASS`

Markdown 必须包含：

- 复用入口
- 需新增/修改的脚本整合点
- 若 `existingCoverage=NONE/PARTIAL`，明确新增用例设计、脚本补齐范围和落地顺序
- 执行产物计划
- 下一步
